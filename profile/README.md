# Streetbeat

Streetbeat builds financial software and data infrastructure for people and AI
agents.

## Public projects

- [Unquant](https://unquant.ai) — a hosted financial-data MCP server for AI
  agents, covering market data, fundamentals, news, macroeconomic data, and US
  Congress disclosures. See the [examples and public contracts](https://github.com/dev-streetbeat/unquant-mcp-examples).
- [Streetbeat τ-bench](https://github.com/dev-streetbeat/streetbeat-tau-bench) —
  a benchmark for evaluating agents in realistic scenarios.
